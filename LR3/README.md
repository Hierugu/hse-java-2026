## Задания

### Задание 1: Создание потоков через класс Thread

**Цель:** Изучить создание потоков путем наследования от класса `Thread`.

**Реализованные классы:**
- `PlaneMaintenanceThread` - поток для технического обслуживания самолета
- `FlightSimulatorThread` - поток для симуляции полета
- `ThreadDemo` - демонстрационный класс

**Ключевые концепции:**
- Наследование от `Thread`
- Переопределение метода `run()`
- Запуск потоков через `start()`
- Использование `join()` для ожидания завершения
- Именование потоков
- Получение информации о состоянии потоков

**Запуск:**
```bash
cd LR3/src
javac -d ../bin common/*.java *.java
java -cp ../bin ThreadDemo
```

### Задание 2: Создание потоков через интерфейс Runnable

**Цель:** Изучить создание потоков через реализацию интерфейса `Runnable`.

**Реализованные классы:**
- `RefuelingTask` - задача заправки самолета
- `BoardingTask` - задача посадки пассажиров
- `PreFlightCheckTask` - задача предполетной проверки
- `RunnableDemo` - демонстрационный класс

**Ключевые концепции:**
- Реализация интерфейса `Runnable`
- Создание потоков через `new Thread(Runnable)`
- Повторное использование задач в разных потоках
- Анонимные классы
- Лямбда-выражения (Java 8+)
- Сравнение с подходом через `Thread`

**Преимущества Runnable:**
- Разделение логики задачи и управления потоком
- Возможность наследования от других классов
- Повторное использование задач
- Более гибкий подход

**Запуск:**
```bash
java -cp ../bin RunnableDemo
```

### Задание 3: Назначение приоритетов потокам

**Цель:** Изучить механизм приоритетов потоков в Java.

**Реализованные классы:**
- `EmergencyLandingTask` - критическая задача (приоритет 10)
- `RoutineMaintenanceTask` - обычная задача (приоритет 5)
- `DataLoggingTask` - фоновая задача (приоритет 1)
- `PriorityDemo` - демонстрационный класс

**Ключевые концепции:**
- Установка приоритетов через `setPriority()`
- Константы: `MIN_PRIORITY` (1), `NORM_PRIORITY` (5), `MAX_PRIORITY` (10)
- Динамическое изменение приоритета
- Влияние приоритетов на выполнение
- Практические сценарии использования

**Важно:**
- Приоритет - это подсказка планировщику, не гарантия
- Реальное поведение зависит от ОС и JVM
- Используйте приоритеты разумно

**Запуск:**
```bash
java -cp ../bin PriorityDemo
```

### Задание 4: Синхронизация потоков

**Цель:** Изучить механизмы синхронизации для безопасной работы с общими ресурсами.

**Реализованные классы:**
- `RunwayController` - контроллер взлетно-посадочной полосы (общий ресурс)
- `FuelTank` - топливный резервуар (паттерн Producer-Consumer)

- `SynchronizationDemo` - демонстрационный класс

**Ключевые концепции:**
- Проблема race condition
- Ключевое слово `synchronized`
- Методы `wait()`, `notify()`, `notifyAll()`
- Паттерн Producer-Consumer
- Взаимное исключение (mutual exclusion)
- Мониторы объектов

**Демонстрируемые сценарии:**
1. Race condition без синхронизации
2. Решение через synchronized
3. Контроль доступа к взлетной полосе
4. Паттерн Producer-Consumer с топливным резервуаром
5. Комплексная синхронизация операций

**Запуск:**
```bash
java -cp ../bin SynchronizationDemo
```

## Основные выводы

### Thread vs Runnable
- **Thread:** Проще для простых случаев, но ограничивает наследование
- **Runnable:** Более гибкий, предпочтительный подход

### Приоритеты
- Используйте для подсказки планировщику
- Не полагайтесь на них для критической логики
- MAX_PRIORITY для критических задач, MIN_PRIORITY для фоновых

### Синхронизация
- Всегда синхронизируйте доступ к изменяемым общим данным
- Используйте `synchronized` для защиты критических секций
- `wait()`/`notify()` только внутри `synchronized`
- Избегайте длительных операций в synchronized блоках
