### Ответы на вопросы

1. **Пакет java.io**  
   Пакет `java.io` содержит классы и интерфейсы для организации ввода‑вывода (I/O) в Java: работу с файлами, потоками данных, буферизацией, сериализацией и т. п. Обеспечивает низкоуровневый доступ к данным (байты, символы) и высокоуровневые абстракции (чтение/запись объектов).

2. **Система ввода/вывода. Потоки данных (stream)**  
   Потоки (`stream`) — абстрактное представление источника ввода (чтение) или цели вывода (запись). В Java различают:  
   - **байтовые потоки** (`InputStream`/`OutputStream`) — работают с данными в виде байтов;  
   - **символьные потоки** (`Reader`/`Writer`) — работают с символами (Unicode).  
   Потоки могут быть связаны с файлами, сетевыми соединениями, памятью и др.

3. **Иерархия классов ввода/вывода**  
   Основная иерархия:  
   - Байтовые потоки:  
     - `InputStream` (абстрактный базовый класс для чтения байтов);  
     - `OutputStream` (абстрактный базовый класс для записи байтов).  
   - Символьные потоки:  
     - `Reader` (чтение символов);  
     - `Writer` (запись символов).  
   От них наследуются конкретные реализации (например, `FileInputStream`, `FileReader`).

4. **Классы InputStream и OutputStream**  
   - `InputStream`: абстрактный класс для чтения последовательности байтов. Основные методы: `read()`, `read(byte[])`, `close()`.  
   - `OutputStream`: абстрактный класс для записи последовательности байтов. Основные методы: `write(int)`, `write(byte[])`, `flush()`, `close()`.  
   Оба класса — основа для всех байтовых потоков.

5. **Классы‑реализации потоков данных**  
   Примеры:  
   - `FileInputStream`/`FileOutputStream` — чтение/запись в файл;  
   - `ByteArrayInputStream`/`ByteArrayOutputStream` — работа с массивом байтов в памяти;  
   - `BufferedInputStream`/`BufferedOutputStream` — буферизированные потоки;  
   - `DataInputStream`/`DataOutputStream` — чтение/запись примитивных типов (int, double и т. п.);  
   - `ObjectInputStream`/`ObjectOutputStream` — сериализация/десериализация объектов.

6. **Классы FileInputStream и FileOutputStream**  
   - `FileInputStream`: читает данные из файла по байтам. Конструктор принимает путь к файлу или объект `File`.  
   - `FileOutputStream`: записывает данные в файл по байтам. Может создавать файл или перезаписывать его.  
   *Пример:*  
   ```java
   try (FileInputStream fis = new FileInputStream("input.txt")) {
       int data = fis.read();
   }
   ```

7. **Классы FilterInputStream и FilterOutputStream и их наследники**  
   - `FilterInputStream`/`FilterOutputStream` — абстрактные классы-декораторы, добавляющие дополнительную функциональность к базовым потокам.  
   - Наследники:  
     - `BufferedInputStream`/`BufferedOutputStream` — буферизация для повышения производительности;  
     - `DataInputStream`/`DataOutputStream` — чтение/запись примитивов;  
     - `CheckedInputStream`/`CheckedOutputStream` — контроль целостности (checksum);  
     - `CipherInputStream`/`CipherOutputStream` — шифрование/дешифрование.

8. **Сериализация объектов (serialization)**  
   Сериализация — преобразование объекта в последовательность байтов для сохранения или передачи. Требования:  
   - Класс должен реализовывать интерфейс `Serializable` (маркерный интерфейс);  
   - Поля `transient` не сериализуются;  
   - Для записи/чтения используются `ObjectOutputStream` и `ObjectInputStream`.  
   *Пример:*  
   ```java
   ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("obj.dat"));
   oos.writeObject(myObject);
   ```

9. **Классы Reader и Writer и их наследники**  
   - `Reader`: абстрактный класс для чтения символов. Методы: `read()`, `read(char[])`, `close()`.  
   - `Writer`: абстрактный класс для записи символов. Методы: `write(String)`, `write(char[])`, `flush()`, `close()`.  
   Наследники:  
   - `FileReader`/`FileWriter` — работа с файлами в кодировке по умолчанию;  
   - `BufferedReader`/`BufferedWriter` — буферизированное чтение/запись;  
   - `InputStreamReader`/`OutputStreamWriter` — преобразование байтов в символы (с указанием кодировки).

10. **Работа с файловой системой**  
    Для работы с файлами и директориями используется класс `java.io.File` (устарел) и пакет `java.nio.file` (современный API):  
    - `Path` и `Paths` — представление путей;  
    - `Files` — утилиты для операций (создание, удаление, копирование, чтение/запись);  
    - `FileVisitor` — обход директорий.  
    *Пример (NIO):*  
    ```java
    Path path = Paths.get("file.txt");
    Files.write(path, "Hello".getBytes());
    ```

11. **Контролируемые исключения (checked exceptions)**  
    Исключения, которые **обязательны для обработки** (компилятор проверяет). Наследуются от `Exception` (но не от `RuntimeException`). Примеры:  
    - `IOException`;  
    - `SQLException`;  
    - `ClassNotFoundException`.  
    Обрабатываются через `try‑catch` или объявляются в `throws`.

12. **Неконтролируемые исключения (unchecked exceptions)**  
    Исключения, которые **не требуют обязательной обработки**. Наследуются от `RuntimeException` или `Error`. Примеры:  
    - `NullPointerException`;  
    - `ArrayIndexOutOfBoundsException`;  
    - `StackOverflowError`.  
    Обычно указывают на ошибки в логике программы.

13. **Иерархия исключений**  
    Все исключения наследуются от класса `Throwable`:  
    - `Error` — критические ошибки (например, `OutOfMemoryError`);  
    - `Exception` — проверяемые исключения;  
      - `RuntimeException` — непроверяемые исключения (подкласс `Exception`).

14. **Методы исключений**  
    Основные методы класса `Throwable`:  
    - `getMessage()` — сообщение об ошибке;  
    - `getCause()` — причина исключения (если есть);  
    - `printStackTrace()` — вывод стека вызовов;  
    - `toString()` — строковое представление исключения.

15. **Обработка исключений — try и catch**  
    Конструкция `try‑catch` позволяет перехватывать и обрабатывать исключения:  
    ```java
    try {
        // код, который может вызвать исключение
    } catch (IOException e) {
        // обработка IOException
    }
    ```
    Блок `try` содержит код, потенциально бросающий исключение; `catch` — обрабатывает конкретное исключение.

16. **Многократные блоки catch**  
    Можно указывать несколько блоков `catch` для разных типов исключений:  
    ```java
    try { ... }
    catch (IOException e) { ... }
    catch (SQLException e) { ... }
    ```
    Порядок важен: сначала более специфические исключения, затем общие.

17. **Ключевые слова throws/throw**  
    - `throws` — указывается в сигнатуре метода, чтобы объявить, что метод может выбросить исключение. Позволяет передать обработку выше по стеку.  
      *Пример:* `void readFile() throws IOException { ... }`  
    - `throw` — явно выбрасывает исключение.  
      *Пример:* `throw new IllegalArgumentException("Ошибка!");`

18. **Блок finally**  
    Блок `finally` выполняется **всегда** после `try` и `catch`, независимо от того, было ли исключение. Используется для освобождения ресурсов (закрытия файлов, соединений и т. п.).  
    *Пример:*  
    ```java
    try { ... }
    catch (Exception e) { ... }
    finally { resource.close(); }
    ```

19. **Создание своих собственных исключений**  
    Чтобы создать собственное исключение, нужно унаследовать класс от `Exception` (для проверяемого) или `RuntimeException` (для непроверяемого):  
    ```java
    public class MyException extends Exception {
        public MyException(String message) {
            super(message);
        }
    }
    ```
    Затем его можно бросать через `throw` и обрабатывать через `try‑catch`.
