# ИТОГОВАЯ СТРУКТУРА ПРОЕКТА

## Созданные файлы

### Исходные коды Java (src/)

1. **Flyable.java**
   - Интерфейс для летающих объектов
   - Определяет методы: takeOff(), land(), fly(), getFuelConsumption()

2. **Maintainable.java**
   - Интерфейс для обслуживаемых объектов
   - Определяет методы: performMaintenance(), getMaintenanceInterval(), needsMaintenance()

3. **Engine.java**
   - Класс двигателя
   - Демонстрирует: перегрузку конструкторов (4 варианта), перегрузку методов (start)
   - Используется в HAS-A relationship с Aeroplane

4. **Vehicle.java**
   - Абстрактный базовый класс транспортного средства
   - Демонстрирует: абстрактные методы, виртуальные методы, перегрузку конструкторов
   - Абстрактные методы: start(), stop(), getType()
   - Виртуальный метод: displayInfo()

5. **Aeroplane.java**
   - Основной класс самолета
   - Наследует Vehicle, реализует Flyable и Maintainable
   - Демонстрирует: IS-A (наследование), HAS-A (агрегация Engine), перегрузку конструкторов и методов
   - Переопределяет все абстрактные и виртуальные методы

6. **PassengerPlane.java**
   - Класс пассажирского самолета
   - Наследует Aeroplane
   - Демонстрирует: многоуровневое наследование, переопределение методов, перегрузку методов
   - Специфические методы: boardPassengers()

7. **CargoPlane.java**
   - Класс грузового самолета
   - Наследует Aeroplane
   - Демонстрирует: многоуровневое наследование, переопределение методов, перегрузку методов
   - Специфические методы: loadCargo(), unloadCargo()

8. **App.java**
   - Главный класс с методом main
   - Полная демонстрация всех концепций ООП
   - Организован в 10 секций, каждая демонстрирует отдельную концепцию

## Реализованные концепции ООП

✅ **Конструкторы и их перегрузка** - Engine (4), Vehicle (3), Aeroplane (4), PassengerPlane (2), CargoPlane (2)

✅ **Перегрузка методов** - start() в Engine, fly() в Aeroplane, boardPassengers() в PassengerPlane, loadCargo() в CargoPlane

✅ **Наследование IS-A** - Vehicle → Aeroplane → PassengerPlane/CargoPlane

✅ **Агрегация HAS-A** - Aeroplane содержит Engine

✅ **Виртуальные методы** - displayInfo() переопределяется во всех подклассах

✅ **Абстрактные классы** - Vehicle с абстрактными методами start(), stop(), getType()

✅ **Полиморфизм** - массивы базового типа Vehicle и Flyable содержат объекты разных типов

✅ **Интерфейсы** - Flyable и Maintainable реализованы в Aeroplane

✅ **Инкапсуляция** - все поля private/protected, доступ через публичные методы

## Компиляция и запуск

### Windows PowerShell:
```powershell
cd src
javac *.java
java App
```

### Или одной командой:
```powershell
cd src ; javac *.java ; if ($?) { java App }
```

3. IS-A Relationship (наследование)
4. Полиморфизм и виртуальные методы
5. Интерфейсы
6. Перегрузка методов
7. Абстрактные классы

9. Интерфейс Maintainable
10. Инкапсуляция
