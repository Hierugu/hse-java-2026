### Ответы на вопросы к лабораторной работе

1. **Объекты в Java**  
   Объект в Java — это экземпляр класса, обладающий **состоянием** (поля/атрибуты) и **поведением** (методы). Объекты создаются с помощью оператора `new` и живут в динамической памяти (heap). Каждый объект имеет уникальный идентификатор (ссылку) и подчиняется правилам, заданным его классом.  
   *Пример:*  
   ```java
   Aeroplane plane = new Aeroplane();
   ```

2. **Классы в Java**  
   Класс — это шаблон (шаблонный тип), описывающий структуру и поведение объектов. Содержит:  
   - поля (переменные класса);  
   - методы (функции, работающие с полями);  
   - конструкторы;  
   - вложенные классы, интерфейсы и т. д.  
   Класс объявляется через ключевое слово `class`.  
   *Пример:*  
   ```java
   public class Aeroplane {
       private String model;
       public void fly() { ... }
   }
   ```

3. **Конструкторы**  
   Конструктор — специальный метод, вызываемый при создании объекта (`new`). Его задача:  
   - инициализировать поля объекта;  
   - гарантировать корректное начальное состояние.  
   Имя конструктора совпадает с именем класса; он не имеет возвращаемого типа. Может быть несколько конструкторов (перегрузка).  
   *Пример:*  
   ```java
   public Aeroplane(String model) {
       this.model = model;
   }
   ```

4. **Создание объекта**  
   Объект создаётся в три этапа:  
   1. Объявление переменной-ссылки (`Aeroplane plane;`).  
   2. Выделение памяти и вызов конструктора через `new` (`new Aeroplane("Boeing 747")`).  
   3. Присвоение ссылки переменной (`plane = new Aeroplane(...);`).  
   После этого объект доступен через ссылку.

5. **Java‑методы**  
   Метод — блок кода, выполняющий определённую задачу. Объявляется так:  
   ```java
   [модификатор] тип_возврата имя(параметры) { ... }
   ```  
   Методы могут:  
   - принимать параметры;  
   - возвращать значение (или `void`);  
   - быть `static` (принадлежат классу) или нестатическими (принадлежат объекту).  
   *Пример:*  
   ```java
   public int getSpeed() { return this.speed; }
   ```

6. **Java — Наследование. IS‑A Relationship. HAS‑A Relationship**  
   - **Наследование** (`extends`): подкласс наследует поля и методы суперкласса. Реализует отношение **IS‑A** («является»).  
     *Пример:* `class FighterJet extends Aeroplane` → «FighterJet является Aeroplane».  
   - **HAS‑A** («имеет»): композиция/агрегация. Объект содержит ссылку на другой объект.  
     *Пример:* `Aeroplane` имеет объект `Engine` → поле `private Engine engine`.

7. **Java — Перегрузка (Overloading)**  
   Перегрузка — наличие нескольких методов с **одним именем**, но **разными параметрами** в одном классе. Компилятор выбирает метод по сигнатуре (типы и количество параметров).  
   *Пример:*  
   ```java
   public void fly(int altitude) { ... }
   public void fly(int altitude, String route) { ... }
   ```

8. **Java — Полиморфизм**  
   Полиморфизм позволяет объектам одного типа вести себя по‑разному в зависимости от реализации. В Java реализуется через:  
   - **Переопределение методов** (`@Override` в подклассе);  
   - **Интерфейсы** (один интерфейс — множество реализаций).  
   *Пример:* метод `fly()` у `Aeroplane` и `FighterJet` может работать по‑разному.

9. **Виртуальные методы**  
   В Java **все не‑`final` не‑`static` методы являются виртуальными** по умолчанию. Это значит, что вызов метода определяется **типом объекта** (а не типа ссылки) во время выполнения (динамическая диспетчеризация).  
   *Пример:*  
   ```java
   Aeroplane plane = new FighterJet();
   plane.fly(); // Вызовется fly() из FighterJet
   ```

10. **Java — Абстрактные классы**  
    Абстрактный класс (`abstract class`) — класс, который:  
    - может содержать абстрактные методы (без реализации, `abstract void fly();`);  
    - не может быть инстанцирован (`new` запрещён);  
    - служит базой для подклассов, обязуя их реализовать абстрактные методы.  
    *Пример:*  
    ```java
    public abstract class Aeroplane {
        public abstract void fly();
    }
    ```

11. **Java — Инкапсуляция**  
    Инкапсуляция — сокрытие деталей реализации и контроль доступа к данным. Достигается через:  
    - модификаторы доступа (`private`, `protected`, `public`);  
    - геттеры/сеттеры для доступа к `private` полям.  
    *Пример:*  
    ```java
    private String model;
    public String getModel() { return model; }
    ```

12. **Java — Интерфейсы**  
    Интерфейс (`interface`) — контракт, определяющий набор методов без реализации. Классы реализуют интерфейсы через `implements`.  
    Особенности:  
    - могут содержать `default` и `static` методы (с реализацией);  
    - поддерживают множественное наследование (класс может реализовывать несколько интерфейсов).  
    *Пример:*  
    ```java
    public interface Flyable {
        void fly();
    }
    public class Aeroplane implements Flyable { ... }
    ```

13. **Java — Пакеты**  
    Пакет (`package`) — механизм группировки классов и интерфейсов в логические модули. Служит для:  
    - избежания конфликтов имён;  
    - контроля доступа (`package‑private`);  
    - структурирования кода.  
    Объявление:  
    ```java
    package com.example.aircraft;
    ```  
    Импорт:  
    ```java
    import com.example.aircraft.Aeroplane;
    ```
